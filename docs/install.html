Install · 两分钟

装到你的电脑上，
浏览器就是工作台。

需要 Python 3.10 与 ffmpeg。装完打开 127.0.0.1:8177 就能开始转谱——没有注册、没有激活、没有用量限制。

  1. 01
    装 Python 3.10

    到 python.org 下载 3.10（不要用 3.13，torch 与 demucs 的轮子还不齐），安装时勾选 “Add python.exe to PATH”。

  2. 02
    取源码

    有 Git 的话直接克隆；没有就下载 ZIP 解压。

    git clone https://github.com/sy666520/M2S.git cd M2S/music2score
  3. 03
    装依赖

    首次会下载 PyTorch，约 2GB，视网络情况 5–20 分钟。有 NVIDIA 显卡的会自动用 CUDA 版本。

    py -3.10 -m pip install -r requirements.txt
  4. 04
    启动

    服务起来后浏览器打开 http://127.0.0.1:8177 就是完整工作台。想要独立窗口（无地址栏），改跑桌面壳。

    py -3.10 -m uvicorn backend.main:app --port 8177 :: 或独立窗口版 py -3.10 desktop/app.py

这台电脑需要

  • Windows 10/11 64 位
  • 内存 8GB 起（分离模型吃内存）
  • 磁盘 6GB 空闲（依赖 + 模型权重）
  • ffmpeg：已在依赖里自带，无需另装

先跑一遍自测

装完不确定环境对不对？跑 py -3.10 tests/smoke.py， 几十秒内会生成一份示例谱，出谱即成功。

  1. 01
    装 Python 3.10 与 ffmpeg
    # macOS brew install python@3.10 ffmpeg # Ubuntu / Debian sudo apt install python3.10 python3.10-venv ffmpeg
  2. 02
    建虚拟环境并装依赖

    别装进系统 Python，避免和系统包打架。

    git clone https://github.com/sy666520/M2S.git cd M2S/music2score python3.10 -m venv .venv && source .venv/bin/activate pip install -r requirements.txt
  3. 03
    启动
    python -m uvicorn backend.main:app --port 8177

    Apple Silicon 会自动走 MPS 加速；Intel Mac 走 CPU，速度约为同价位 PC 的一半。

说明

  • M 系列芯片：MPS 加速可用
  • Linux 服务器：加 --host 0.0.0.0 可供局域网其他电脑访问
  • 桌面壳依赖 WebKit，macOS 自带

打印友好

导出的简谱与六线谱是矢量 SVG，A4 直出不失真，可交给打印店装订。

  1. 01
    克隆与安装
    git clone https://github.com/sy666520/M2S.git cd M2S/music2score py -3.10 -m pip install -r requirements.txt
  2. 02
    跑自测

    不依赖显卡，几十秒跑完；能出谱说明环境没问题。

    py -3.10 tests/smoke.py
  3. 03
    改商业开关（可选）

    默认全免费。要启用「每日额度 + 推广位 + 激活码」把 data/billing.json 里 enabled 改 true； 生成激活码还需自备环境变量 M2S_LICENSE_SECRET（不随代码分发）。

仓库

  • 许可证：MIT，可商用、可闭源分发
  • 后端：FastAPI + PyTorch
  • 前端：原生 JS，无构建步骤
  • 渲染：Verovio（五线谱）+ 自写简谱 / TAB

参与

问题与建议走 GitHub Issues。 识别层是插件式的：实现 Transcriber 接口并注册，就能换算法。

对照

三种用法，选一个

形态适合
浏览器打开 127.0.0.1就在这台电脑上用，最快，零额外步骤
桌面独立窗口想要 App 感、没有地址栏，适合长时间校对
局域网另一台电脑同一 Wi-Fi 下的备用机，打开电脑 IP 即可，无需重复安装
